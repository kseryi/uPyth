Про uPyth

uPyth — навчальне середовище, створене для плавного переходу від блокового програмування (на кшталт Scratch) до текстового програмування мовою Python.

Через свою спеціалізацію та певні обмеження uPyth не претендує на заміну професійних середовищ розробки — його мета виключно освітня.

1) Blockly

2) Python Code

Change blocks — code updates automatically.

3) Execution
