# Уроки (alpha)

Усі уроки — це XML-файли в цій папці: `lessons/<id>.xml`.
Один файл містить і блоки уроку, і його теорію.

## Структура файлу

```xml
<xml xmlns="https://developers.google.com/blockly/xml">
  <lesson id="turtle-square">
    <title lang="uk">Квадрат за допомогою черепашки</title>
    <title lang="en">Drawing a square with a turtle</title>
  </lesson>
  <theory lang="uk"><![CDATA[ <h2>…</h2><p>…</p> ]]></theory>
  <theory lang="en"><![CDATA[ <h2>…</h2> ]]></theory>
  <!-- далі — звичайні блоки Blockly -->
  <block type="flag_start" x="20" y="20"> … </block>
</xml>
```

- `<lesson id>` — ідентифікатор. Якщо він збігається з `id` в `js/lessons.js`
  (`LESSON_GROUPS`), урок з'являється в каталозі «📖 Уроки».
- `<title lang>` — назва уроку (показується в заголовку панелі, якщо немає ключа з локалі).
- `<theory lang format="md">` — теорія. Вибирається мова інтерфейсу, резерв — `uk`.
  `format="md"` — Markdown (пише редактор, ✏️ у панелі). Без `format` або з `format="html"` —
  HTML як є (старі уроки). Редактор HTML не відкриває, пропонує перевести на Markdown.
- Блоки — звичайні Blockly-блоки (їх можна зберегти з редактора через «💾 Save .xml»
  і додати до них `<lesson>` та `<theory>` вручну).

## Вбудовані матеріали

- **Зображення** — як `data:`-URI прямо в `src`, наприклад для SVG:
  `<img src="data:image/svg+xml;base64,…" alt="…">`.
  Так файл лишається самодостатнім, без окремих картинок.
- **Відео** — поки що через вбудування (iframe), наприклад YouTube:
  `<div class="lp-video"><iframe src="https://www.youtube-nocookie.com/embed/ID" allowfullscreen></iframe></div>`.
  Локальне відео можна вбудувати як `<video controls src="data:video/mp4;base64,…">`,
  але файл при цьому стає великим.
- **Код** — `<pre><code>…</code></pre>`.

## Як відкрити урок

1. **Каталог:** «📖 Уроки» → плитка уроку. Блоки і теорія завантажуються разом.
2. **Файл:** «📂 Load .xml» → оберіть будь-який `.xml` з вузлом `<theory>`.
   Панель теорії з'явиться автоматично.

Кнопки панелі: `‹` / `›` — попередній/наступний урок каталогу (для уроку з файлу стрілки
вимкнені); «Закрити» або Esc — сховати; ліву межу можна перетягнути.

## Редактор теорії (✏️)

Кнопка ✏️ у заголовку панелі відкриває редактор. Порожній проєкт теж можна описати:
✏️ створює власний урок. «💾 Save .xml» зберігає урок і теорію разом з блоками.

Markdown-підмножина (рендер безпечний: сирий HTML не виконується):

- `# Заголовок`, `## Підзаголовок`, `### …`
- `**жирний**`, `*курсив*`, `` `код` ``
- блок коду: ```` ```python ```` … ```` ``` ````
- зображення: `![опис](https://…)` або файл з диска, вбудовується як data:-URI.
  Переважно SVG (схеми): скрипти, обробники подій і зовнішні посилання з SVG видаляються.
  Фото: PNG або JPEG до 300 КБ. GIF і WebP не приймаються.
- посилання: `[текст](https://…)`
- список: `- пункт`
- відео: `@video(посилання YouTube або Vimeo)`

Зображення з `http://` (без `s`) і посилання з інших протоколів не показуються.
