# Джерела бібліотек у цій папці

Файли в цій теці — це реальний, перевірений код офіційних бібліотек
MicroPython (не вигаданий і не "приблизний"), скопійований з
https://github.com/micropython/micropython-lib за ліцензією MIT.
Ваше середовище (`js/extensions/pico.js`) бере код САМЕ ЗВІДСИ (а не з
localStorage браузера чи з інтернету під час роботи) — тому воно
завжди відповідає тому, що реально лежить у цій папці, і ви можете
самі оновити/замінити будь-який файл тут, коли вийде нова версія
бібліотеки.

| Файл                 | Джерело (офіційний репозиторій)                                                                                  |
|----------------------|--------------------------------------------------------------------------------------------------------------------|
| `ssd1306.py`         | micropython/micropython-lib → `micropython/drivers/display/ssd1306/ssd1306.py` |
| `umqtt/simple.py`    | micropython/micropython-lib → `micropython/umqtt.simple/umqtt/simple.py`       |
| `umqtt/robust.py`    | micropython/micropython-lib → `micropython/umqtt.robust/umqtt/robust.py`       |

Ліцензія оригіналів: MIT (https://github.com/micropython/micropython-lib/blob/master/LICENSE).

## Чому тут НЕ всі бібліотеки зі списку

Для `st7789`, `ili9341`, `lcd1602`, `bh1750`, `bmp280`/`bme280`,
`mpu6050`, `hcsr04`, `servo`, `stepper`, `pca9685`, `sdcard` не існує
ЄДИНОГО офіційного канонічного драйвера в micropython-lib — є багато
різних community-реалізацій з різною розпіновкою/конструктором, і
підсунути "якусь одну" видавши за стандартну було б нечесно й могло б
не підійти саме під ваше залізо. Для них у вікні "📚 Бібліотеки"
передбачено імпорт власного .py-файлу — після імпорту він так само
кешується (в localStorage браузера) і використовується для всіх
майбутніх проєктів, аналогічно до файлів із цієї теки. Якщо хочете —
покладіть перевірений .py файл драйвера прямо сюди
(`libraries/<назва>.py`) і додайте його як `bundled` у каталозі в
`js/extensions/pico.js` — середовище одразу почне брати його звідси.
