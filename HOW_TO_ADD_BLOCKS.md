# Як додати новий блок і команду Python

Це покроковий алгоритм для розширення редактора. Кожен блок складається з
**трьох незалежних частин**, і всі три обов'язкові:

1. **Визначення блоку** — як він виглядає (Blockly.Blocks / JSON)
2. **Генератор** — який Python-код він видає (`PY['тип_блоку'] = ...`)
3. **Toolbox** — щоб блок з'явився в панелі команд (index.htm)

Забудете хоч одну частину — і: блок не з'явиться (немає toolbox), або
з'явиться, але не працюватиме (немає генератора → у консолі буде
"Немає генератора для типу блоку: ..." і Python-код просто не згенерується
для цього блоку).

---

## Крок 1. Визначення блоку

Відкрийте `src/core/blocks-turtle.js`, знайдіть функцію `defineBlocksAndGenerators()`.
Є два способи визначити блок:

### А) Простий блок — через JSON (масив у `Blockly.defineBlocksWithJsonArray([...])`)

Підходить для блоків без спадного списку (dropdown) чи складної логіки.

```js
{
  type: "t_wait",                                  // унікальна назва типу
  message0: "Wait %1 seconds",                      // текст на блоці, %1 = місце інпута
  args0: [{ type: "input_value", name: "SECONDS", check: "Number" }],
  previousStatement: null,                           // блок можна вставити ПІСЛЯ іншого
  nextStatement: null,                                // і ПІСЛЯ нього можна вставити ще один
  colour: "#0ea5e9",
  tooltip: "Призупиняє виконання на вказану кількість секунд"
}
```

Додайте цей об'єкт у масив, що передається в
`Blockly.defineBlocksWithJsonArray([...])` (він вже містить багато інших
блоків — просто впишіть свій між ними, через кому).

### Б) Блок зі спадним списком (dropdown) — через `Blockly.Blocks[...]`

```js
Blockly.Blocks['pick_animal'] = {
    init: function() {
        this.appendDummyInput()
            .appendField("Animal")
            .appendField(new Blockly.FieldDropdown([
                ["cat", "cat"], ["dog", "dog"], ["fox", "fox"]
            ]), "ANIMAL");
        this.setOutput(true, "String");   // це VALUE-блок (повертає значення)
        this.setColour('#22c55e');
        this.setTooltip("Обрати тварину зі списку");
    }
};
```

**Statement-блок** (виконує дію, з'єднується зверху/знизу) — використовує
`setPreviousStatement(true, null)` + `setNextStatement(true, null)`.
**Value-блок** (повертає значення, вставляється в "гніздо" іншого блоку,
як число чи рядок) — використовує `setOutput(true, "Тип")` замість
prev/next. Ці два типи НЕ можна поєднувати в одному блоці.

Якщо блок має вкладені блоки всередині (як "repeat" чи "if") — додайте
`this.appendStatementInput('DO');` (назва 'DO' довільна, але має
збігатися з назвою в генераторі).

## Крок 2. Генератор Python

У тій самій функції, трохи нижче, є розділ з рядками `PY['...'] = ...`.
Додайте свій:

### Statement-блок (виконує дію) — повертає ГОТОВИЙ РЯДОК з `\n` в кінці:

```js
PY['t_wait'] = block => {
    const seconds = valueToCode(block, 'SECONDS', '1');   // 'SECONDS' = ім'я інпута з Кроку 1
    return `time.sleep(${seconds})\n`;                     // не забудьте \n!
};
```

⚠️ Якщо команда використовує модуль, якого нема серед готових
`import_turtle`/`import_random`/`import_math` (наприклад тут — `time`),
або додайте свій блок `import_time` за зразком існуючих `import_random`/
`import_math`, або одразу вставте `import time` у самому генераторі
(менш акуратно, але працює):
```js
PY['t_wait'] = block => `import time\ntime.sleep(${valueToCode(block, 'SECONDS', '1')})\n`;
```

### Value-блок (повертає значення) — повертає МАСИВ `[код, 0]`:

```js
PY['pick_animal'] = block => {
    const animal = block.getFieldValue('ANIMAL');
    return [`"${animal}"`, 0];   // другий елемент (0) не використовується — просто заглушка
};
```

### Блок із вкладеними блоками (як "repeat"/"if") — використайте `statementToCode`:

```js
PY['my_loop'] = block => {
    const times = valueToCode(block, 'TIMES', '1');
    const body = statementToCode(block, 'DO');  // САМ додає відступи (4 пробіли) і обробляє весь ланцюжок вкладених блоків
    return `for _ in range(${times}):\n${body}`;
};
```

**Корисні функції, які вже є в файлі і які можна викликати з будь-якого
генератора:**
- `valueToCode(block, 'ІМ'Я_ІНПУТА', 'значення_за_замовчуванням')` — код
  підключеного value-блоку (або значення за замовчуванням, якщо нічого
  не підключено)
- `statementToCode(block, 'ІМ'Я_STATEMENT_ВХОДУ')` — код вкладених
  блоків, вже з відступом
- `toIdentifier(текст, запасне_ім'я)` — перевіряє, що текст є коректним
  Python-ідентифікатором (без пробілів/спецсимволів), інакше повертає
  запасне ім'я

## Крок 3. Toolbox (щоб блок з'явився в панелі)

Відкрийте `index.htm`, знайдіть `<xml id="toolbox">`. Знайдіть категорію,
куди логічно вписати блок (або створіть нову `<category name="...">`), і
додайте рядок з типом блоку:

```html
<category name="Pen" colour="#22c55e">
    ...
    <block type="t_wait">
        <value name="SECONDS"><shadow type="math_number"><field name="NUM">1</field></shadow></value>
    </block>
</category>
```

`<value name="...">` з `<shadow>` всередині — це "блок за замовчуванням",
який видно напівпрозорим у гнізді, поки користувач не підключить щось
своє. Ім'я в `<shadow>` необов'язкове — можна й без нього, якщо у
`valueToCode` вказано розумне значення за замовчуванням.

## Крок 4. Перевірка

1. Оновіть сторінку в браузері.
2. Знайдіть свій блок у відповідній категорії панелі команд.
3. Перетягніть його на робочу область, підключіть до інших блоків.
4. Подивіться на панель "2) Python Code" — там одразу має з'явитись
   згенерований код.
5. Натисніть "▶ Run".

Якщо код НЕ з'являється (або з'являється порожнім) — відкрийте консоль
розробника браузера (F12 → Console) і перевірте, чи нема повідомлення
"Немає генератора для типу блоку: ..." — це означає, що Крок 2 забуто
або в назві типу блоку є одруківка (типи в Кроках 1–3 мають збігатись
**符号-в-символ**, включно з великими/малими літерами).

## ⚠️ Важливе застереження

Ця збірка `blockly.min.js` — не повна: у ній **немає, наприклад, модуля
"colour"** (`colour_picker`, `colour_random` тощо). Спроба додати такий
блок у toolbox кидає помилку `Invalid block definition for type: ...`,
яка ламає відображення панелі команд для ВСІХ категорій одразу (саме
через це блоки "зникали" при клікані по категоріях — цей конкретний
випадок вже виправлено у v5, видаленням `colour_picker`).

**Правило:** якщо додаєте блок, якого НЕ було у списку в цьому проєкті
раніше (не з наших `PY[...]`), і не впевнені, що він точно є в
`js/blockly.min.js` — перевірте це першим ділом:

```bash
grep -c "назва_типу_блоку" js/blockly.min.js
```

Якщо результат `0` — блоку немає в збірці, і краще написати власний
(як у Кроці 1, варіант А чи Б), а не покладатись на вбудований.

## Повний приклад "з нуля": блок "Say Hello N times"

**Крок 1 (JSON, у масиві Blockly.defineBlocksWithJsonArray):**
```js
{
  type: "say_hello_n_times",
  message0: "Say hello %1 times",
  args0: [{ type: "input_value", name: "N", check: "Number" }],
  previousStatement: null,
  nextStatement: null,
  colour: "#8059ff",
  tooltip: "Виводить 'Hello!' вказану кількість разів"
}
```

**Крок 2 (генератор):**
```js
PY['say_hello_n_times'] = block => {
    const n = valueToCode(block, 'N', '1');
    return `for _ in range(${n}):\n    print("Hello!")\n`;
};
```

**Крок 3 (toolbox, категорія "Output"):**
```html
<block type="say_hello_n_times">
    <value name="N"><shadow type="math_number"><field name="NUM">3</field></shadow></value>
</block>
```

Готово — після оновлення сторінки блок працює.

## Приклад 2: нова ГРУПА (категорія) "Масиви" + блок "з комірками та плюсиком"

Це реальний приклад, вже додаkgо у проєкт — покроково, як саме це робилось.
Різниця з Прикладом 1: тут блок ("список з елементами") — **стандартний
блок Blockly**, який вже вміє показувати комірки з кнопками "+"/"−"
(шестерня-mutator). Тому Кроку 1 (визначення блоку) взагалі не потрібно —
блок вже визначений всередині `js/blockly.min.js`. Залишаються лише
Крок 2 (генератор) і Крок 3 (toolbox).

### Крок 1 — ПЕРЕВІРКА: чи є потрібний блок у збірці

Перед тим як писати щось своє, перевірте, чи Blockly вже має готовий блок
(це збереже купу часу — не треба винаходити mutator-логіку "+/−" самому):

```bash
grep -c "lists_create_with" js/blockly.min.js
```

Результат `1` (чи більше) означає: блок `lists_create_with` є в збірці.
Це і є "блок з комірками та плюсиком" — офіційний блок Blockly "create
list with", де іконка-шестерня відкриває міні-редактор, що дозволяє
натисканням +/− додавати чи прибирати комірки-елементи списку.

### Крок 2 — Генератор Python

У `src/core/blocks-turtle.js`, у розділі з `PY['...'] = ...`, додайте:

```js
PY['lists_create_with'] = block => {
    const parts = [];
    let i = 0;
    // комірки блоку називаються ADD0, ADD1, ADD2... — цикл їх усі збирає,
    // скільки б користувач не додав через "+"
    while (block.getInput('ADD' + i)) {
        parts.push(valueToCode(block, 'ADD' + i, '0'));
        i++;
    }
    return [`[${parts.join(', ')}]`, 0];   // Python-список: [1, 2, 3]
};
```

Корисно одразу додати й "сусідні" операції над списками (теж вже готові
в Blockly, лише потребують генератора):

```js
PY['lists_length']  = block => [`len(${valueToCode(block, 'VALUE', '[]')})`, 0];
PY['lists_isEmpty']  = block => [`(len(${valueToCode(block, 'VALUE', '[]')}) == 0)`, 0];
```

`lists_getIndex`/`lists_setIndex` (отримати/змінити елемент за номером)
трохи складніші — мають поле `WHERE` (з початку/з кінця/перший/
останній/випадковий) і 1-індексацію (для новачків рахувати з 1, а не з
0). Повну версію дивіться в `src/core/blocks-turtle.js` — вона вже реалізована й
протестована.

### Крок 3 — Toolbox: нова категорія

У `index.htm`, у `<xml id="toolbox">`, додайте нову `<category>`:

```html
<category name="Масиви" colour="#f97316">
    <block type="lists_create_with">
        <mutation items="3"></mutation>   <!-- скільки комірок показати одразу -->
    </block>
    <block type="lists_length"></block>
    <block type="lists_isEmpty"></block>
    <block type="lists_getIndex">
        <value name="AT"><shadow type="math_number"><field name="NUM">1</field></shadow></value>
    </block>
</category>
```

### Крок 4 — Перевірка

1. Оновіть сторінку.
2. Знайдіть категорію "Масиви" в панелі.
3. Перетягніть "create list with" на поле — побачите 3 комірки.
4. Клікніть на **шестерню зліва на блоці** — відкриється міні-вікно з
   "list" ліворуч і "item" праворуч; перетягніть "item" в список
   праворуч, щоб додати комірку (або заберіть — щоб прибрати).
5. У кожну комірку підключіть число/текст/будь-який блок-значення.
6. Подивіться на панель "2) Python Code" — має з'явитись, наприклад,
   `[1, 2, 3, 4]`.

### Загальний висновок з цього прикладу

Перш ніж писати блок "з нуля" (Приклад 1), **завжди спершу перевіряйте**,
чи Blockly вже має готовий (Крок 1 з Прикладу 2) — це економить час і
дає готову, перевірену роками mutator-логіку "+/−" безкоштовно. Якщо
такого блоку немає — тоді дійсно потрібен весь алгоритм з Прикладу 1.

## Додаток: система "модулів" (Turtle / Tkinter / Raspberry Pi Pico)

З версії, де середовище стартує з "голого" Python, категорії й import-блоки
модулів (Turtle/Tkinter/Pico і будь-які майбутні) керуються не напряму
через `index.htm`, а через `js/extensions.js` + `window.registerModule` /
`window.registerExtension`. Коротко:

- **Turtle** — "вбудований" (`core`) модуль: блоки визначені прямо в
  `src/core/blocks-turtle.js` (як і раніше), але категорії Movement/Pen/Shapes ховаються,
  доки модуль не увімкнено. Дескриптор реєструється викликом
  `window.registerModule('turtle', {...})` одразу після `window.PY = {}`
  на початку `src/core/blocks-turtle.js`.
- **Tkinter / Raspberry Pi Pico** — динамічні розширення
  (`js/extensions/tkinter.js`, `js/extensions/pico.js`), що
  довантажуються лише коли модуль увімкнено. Кожен файл викликає
  `registerExtension('id', function(ctx) { ...; return descriptor; })`.

`descriptor` — об'єкт із полями `colour`, `categoryIds` (для вже наявних
у toolbox категорій, які треба ховати/показувати) АБО `categoryXml`
(повністю нова категорія), `startBlocksXml` (import-блоки, що з'являються
в категорії "Start" — пофарбовані кольором модуля) і, опційно, `panel`
(`{ mount(container) }` — щоб адаптувати 3-тю панель виконання, як це
робить Pico з платою замість полотна).

Щоб додати ще один модуль — скопіюйте `js/extensions/pico.js` (найпростіший
приклад) і додайте один запис у `MODULE_CATALOG` в `js/extensions.js`
(`id`, `name`/`nameEn`, `description`/`descriptionEn`, `script`, і функцію
`detect(blockType)`, яка визначає "цей блок належить моєму модулю" — вона
потрібна для автоматичного вмикання модуля при завантаженні `.xml`, у
якому вже є блоки цього модуля).
